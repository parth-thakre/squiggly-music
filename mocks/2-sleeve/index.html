A desktop player for Navidrome that leaves the signal alone.

Download for Windows Download for Fedora

Squiggly asks Navidrome for the original file, plays it through libmpv, and tells you what it knows about the signal path.

What it does

Browse records, artists, playlists, and favorites, and search across them. Build automatic playlists by genre, by decade, and from what's new. Start a radio station from any song, record, or artist.

Edit the queue and your playlists; the queue follows you between devices through the server. Synced lyrics fill in word by word from your server, and looking up missing ones on LRCLIB is off until you turn it on.

Mini player, tray, media keys, and the system media controls: the Windows media flyout, MPRIS on Linux. Files from your computer play with their own cover and tags. Ctrl+K finds any action; keys live in keybindings.json; colour themes are files; extensions are folders of TypeScript that reload when you save.

What it does to the signal

Nothing. No EQ, no crossfade, no loudness levelling, no ReplayGain. It starts at 100% volume, and if you turn it down it says that's attenuation. On Windows it can ask for exclusive output, and it reports what mpv accepted rather than claiming more.

Trust

MIT licensed. Each release has SHA256SUMS. The Windows builds carry an audio-only LGPL libmpv, built reproducibly from source, with its complete source in the release. The builds aren't code-signed yet, so Windows SmartScreen warns: More info, then Run anyway. The installed Windows app updates itself from GitHub releases; the portable exe and the RPM say when a new version is out. Nothing about you is sent.
