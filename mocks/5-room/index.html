Squiggly plays your own music from your own server.

Download for Windows Download for Fedora

A desktop player for Navidrome, or anything OpenSubsonic.

Records, artists, playlists, favorites. Radio from any song.

  • Search across your library. Automatic playlists by genre, by decade, and from what's new.
  • Edit the queue and your playlists. The queue follows you between devices through the server.
  • Mini player, tray, media keys, the Windows media flyout, MPRIS on Linux. Files from your computer play with their own cover and tags.
  • Ctrl+K finds any action. Keys in keybindings.json, themes as files, extensions as folders of TypeScript that reload when you save.

Lyrics come from your server. LRCLIB is off until you turn it on.

Word by word.

The original file, through libmpv. No EQ, no crossfade, no loudness levelling, no ReplayGain.

It leaves the signal alone.

Below 100% is attenuation, and it says so. On Windows it can ask for exclusive output, and reports what mpv accepted rather than claiming more. What it can't see, it leaves blank.

Served from your own machine. Same library, same queue.

On your phone, too.

Version 0.1.0. Windows 10/11 and Fedora. There are no macOS builds. It's early software.

  • Windows installerx64
  • Windows portablex64, nothing to install
  • Fedora RPMx86_64, pulls in mpv-libs
  • SHA256SUMSto check the files above

MIT licensed. The Windows builds carry an audio-only LGPL build of libmpv, built reproducibly from source; its complete source ships with each release.

Not code-signed yet, so Windows SmartScreen warns: More info, then Run anyway. The installed Windows app updates itself from GitHub releases; the portable exe and the RPM say when a new version is out. Nothing about you is sent.

No server yet? Navidrome runs a public demo full of Creative Commons music: demo.navidrome.org, username demo, password demo. It's Navidrome's, shared by everyone, and may be slow or reset.
