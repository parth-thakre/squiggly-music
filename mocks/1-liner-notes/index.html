Squiggly

Squiggly Version 0.1.0 Windows 10/11 · Fedora · a browser version for phones MIT

A desktop player for Navidrome that asks for the original file, plays it through libmpv, and leaves the signal alone.1

Download for Windows Download for Fedora Source on GitHub

Side A

  1. Library Records, artists, playlists, favorites, and search across them. Automatic playlists by genre, by decade, and from what's new. Radio from any song, record, or artist.
  2. Queue Edit the queue and your playlists. The queue follows you between devices through the server.
  3. Lyrics Synced lyrics fill in word by word. They come from your server.5
  4. Desktop Mini player, tray, media keys, and the system media controls: the Windows media flyout, MPRIS on Linux. Files from your computer play with their own cover and tags.
  5. Yours to change Ctrl+K finds any action. Keys live in keybindings.json, colour themes are files, and extensions are folders of TypeScript in the config folder that reload when you save.

No EQ, no crossfade, no loudness levelling, no ReplayGain.

What the app does to the signal. On Windows it can ask for exclusive output, and it reports what mpv accepted rather than claiming more.

  1. Squiggly starts at 100% volume and turns ReplayGain off. Anything below 100% is attenuation, and the signal-path line says so. What it can't see, such as what the system mixer does after mpv, it leaves blank rather than guessing. ↩
  2. The builds aren't code-signed yet, so Windows SmartScreen warns you: choose More info, then Run anyway. Check what you downloaded with sha256sum --ignore-missing -c SHA256SUMS. ↩
  3. The Windows builds carry an audio-only LGPL build of libmpv, built reproducibly from source. Its complete source ships with each release. Fedora uses the system's mpv-libs. ↩
  4. The installed Windows app updates itself. The portable exe and the RPM say when a new version is out and link to it. ↩
  5. Looking up missing lyrics on LRCLIB is off until you turn it on. ↩
