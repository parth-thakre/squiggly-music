A desktop player for Navidrome that leaves the signal alone.

Squiggly asks the server for the original file, hands it to libmpv, and tells you what it knows about the signal path. It doesn't process the audio. Where it can't see, such as what the system mixer does after mpv, it says nothing rather than guessing.

Signal path

  1. Navidromeyour server; or anything OpenSubsonic
  2. original fileasked for as-is (format=raw); the app can't prove the server sent it untouched
  3. libmpvdecodes; starts at 100%, ReplayGain off, no EQ or crossfade
  4. audio-out-paramswhat mpv handed to the system; on Windows, exclusive output on request
  5. mixer, DACmay still change it; not visible to the app

Matching sample rates don't prove bit-perfect output. The app reports what it can see and leaves the rest blank.

Specifications

library
records, artists, playlists, favorites; search; automatic playlists by genre, by decade, and from what's new; radio from any song, record, or artist
queue
editable, with playlists; follows you between devices through the server
lyrics
synced, word by word, from your server; LRCLIB lookup optional, off by default
desktop
mini player, tray, media keys; Windows media flyout, MPRIS on Linux; local files with their own cover and tags
processing
none: no EQ, crossfade, loudness levelling, or ReplayGain; volume below 100% is reported as attenuation
output
Windows: exclusive output on request; the app reports what mpv accepted
playback
libmpv; Windows builds carry an audio-only LGPL build, reproducible from source, source shipped with each release; Fedora uses mpv-libs
sign-in
remembered; password kept only as your system encrypts it
customising
Ctrl+K command palette; keybindings.json; colour themes as files; extensions as folders of TypeScript that reload on save
updates
from GitHub releases; the installed Windows app updates itself; portable and RPM notify; nothing about you is sent
platforms
Windows 10/11 x64 (installer, portable); Fedora x86_64 (RPM); browser version for phones; no macOS builds
verification
SHA256SUMS per release; not code-signed yet, so Windows SmartScreen warns (More info, then Run anyway)
