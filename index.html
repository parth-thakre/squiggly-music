The desktop player

Squiggly plays your own music from your own server. It asks for the original file, plays it through libmpv, and tells you what it knows about the signal path.

It leaves the signal alone.

No EQ, no crossfade, no loudness levelling, no ReplayGain. It starts at 100% volume, and if you turn it down it says that's attenuation. On Windows it can ask for exclusive output, and it reports what mpv accepted rather than claiming more.

Check what you download.

  • Open source under MIT. Each release carries SHA256SUMS.
  • The Windows builds include an audio-only LGPL build of libmpv, built reproducibly from source. Its complete source ships with each release.
  • The builds aren't code-signed yet, so Windows SmartScreen warns: More info, then Run anyway.
  • The installed Windows app updates itself from GitHub releases. The portable exe and the RPM say when a new version is out. Nothing about you is sent.
